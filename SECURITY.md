# Seguridad

No abras un issue público con cookies, tokens, URLs privadas o datos de cuenta.
Revoca inmediatamente cualquier sesión de X que hayas compartido por error.

SpaceFlow guarda `cookies.txt` fuera del código y aplica permisos `0600` en
sistemas compatibles. El archivo está excluido por `.gitignore`, pero cada
persona sigue siendo responsable de revisar un commit antes de publicarlo.

Las actualizaciones automáticas solo se instalan después de verificar el hash
SHA-256 publicado en la misma GitHub Release.
